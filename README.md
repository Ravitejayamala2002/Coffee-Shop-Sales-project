# ☕ Coffee Shop Sales Dashboard

![Coffee Shop Sales Dashboard](./fd4f2578-4331-4e04-a35a-940df95691a2.png)

## 📊 Overview

This project presents an interactive sales dashboard for a coffee shop, designed using tools like Power BI. The dashboard provides comprehensive insights into product performance, customer preferences, and store-level sales distribution.

## 📌 Features

- **Total Sales Overview**  
  Displays total sales (699K), total quantity sold (214K), number of locations (149K), and transactions (11bn).

- **Sales by Product Category**  
  Bar chart showcasing the performance of various product categories such as Coffee, Tea, Bakery, and others.

- **Sales by Store Location**  
  Pie chart comparison of sales in three store locations:  
  - Lower Manhattan  
  - Astoria  
  - Hell's Kitchen

- **Sales by Product Type**  
  Visual breakdown by product types like Espresso, Brewed Coffee, Hot Chocolate, and more.

- **Sales by Month**  
  Month-wise bar chart to show sales trends from January to June.

- **Detailed Sales Table**  
  Tabular view of product details, categories, and quantities for granular analysis.

- Coffee and Tea are top-selling categories.
